# DTXmaniaNXT の詳しい使い方

[README](../README.ja.md) に載せきれない、詳しい使い方をまとめています。新しい機能を追加したときは、ここに説明を書き足してください。

## ダウンロード

[リリース](https://github.com/check5004/DTXmaniaNXT/releases/latest)から、Windows は [DTXmaniaNXT-Setup.exe](https://github.com/check5004/DTXmaniaNXT/releases/latest/download/DTXmaniaNXT-Setup.exe)（常に最新のバージョン）をダウンロードして実行します。管理者の権限なしで `%LocalAppData%\DTXmaniaNXT` にインストールして起動し、スタートメニューとデスクトップに DTXmaniaNXT が入ります。画面の画像と効果音もアプリに入っているので、ほかに何も用意しなくても遊べます。画面の配置は DTXManiaNX v2.0 と同じで、絵と音は DTXmaniaNXT のために作ったものです。macOS（Apple シリコン）と Linux（x86_64）向けのファイルも同じページにあります。

- 署名をしていないので、Windows で「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押します。
- 新しいバージョンは、起動したときに GitHub のリリースにあるかを確かめ、あればタイトルのメニューの下に「新しいバージョン」の行が出ます。その行を選ぶとダウンロードが始まり（ダウンロード中は画面の隅に % が出て、そのまま遊べます）、終わったら「再起動してアップデート」で新しいバージョンに切り替えて起動し直します。選ばずに終了しても、そのときにアップデートされます。設定の「全般」の「アップデート」で、お知らせ（既定）・自動（起動したときにダウンロードし、終了したときにインストールする）・確認しない を選べます。
- 設定と記録は別のフォルダ（下の `%APPDATA%\DTXmaniaNXT`）にあるので、更新しても、入れ直しても引き継がれます。exe 単体で使っていた人も、Setup.exe で一度入れ直せばそのまま使えます（古い exe は消してかまいません）。
- アンインストールは Windows の設定の「アプリ」から行います。設定と記録は残ります。
- まだリリースしていない変更を試すときは、[Actions](https://github.com/check5004/DTXmaniaNXT/actions) で成功した CI の実行を開き、下の Artifacts から `dtxmanianxt-Windows` をダウンロードします（macOS は CI (macOS) の実行の `dtxmanianxt-macOS`）。

## 遊び方

1. 起動すると NX と同じタイトルの画面になります（Start / Config / Quit。曲を探しているあいだは左上に印が出ます）。画面の下には、設定の画面と同じ操作の案内の帯を出します（↑↓ か HT / LT で選び、Enter か CY / RD で決め、Esc で終わります。叩き間違えで終わらないよう、LC は使いません）。初めは Config の「曲」にある「フォルダを追加」で曲のフォルダを選びます。曲のフォルダをウィンドウにドロップしても追加できます（DTXManiaNX の曲を使うなら、NX のフォルダか、その中の曲のフォルダを選びます）。
   - 曲の追加：ダウンロードした zip ファイルや曲のフォルダをウィンドウにドロップすると、「曲の追加先」（初めは 1 つ目の曲のフォルダ）へコピーし、曲を探し直してその曲を選びます。いくつでもまとめてドロップできます。重ねているあいだは画面に追加先を出し、コピーしているあいだは右下に進み具合を出します（演奏中は出さず、終わってから知らせます）。追加した曲には、起動しているあいだ NEW の印が付きます。
     - zip の中身が 1 つのフォルダに入っていればそのフォルダ名で、譜面が zip の一番上にじかにあれば zip の名前でフォルダを作ります。日本の Windows で作った zip のファイル名（Shift_JIS）もそのまま読めます。
     - 同じ名前のフォルダがあるときは、中身が同じならコピーせずにその曲を選び、違えば「名前 (2)」にします。前からある曲は上書きしません。
     - 曲のフォルダがまだ無いときにドロップしたフォルダと、50 曲より多いフォルダは、コピーせずにその場所のまま曲のフォルダに足します。曲のフォルダの中のフォルダをドロップしたときは、探し直してその曲を選びます。曲のフォルダが無いときにドロップした zip は、ドキュメントの DTXmaniaNXT\Songs に入れ、そこを曲のフォルダにします。
     - 読めるのは zip（Deflate）だけです。RAR・7z・LZH は展開してからフォルダをドロップしてください。パスワード付きの zip と、展開すると大きすぎるものは追加しません。zip の中の名前に `..` などがあっても、追加先の外には書きません。
   - 0.1 で「NX Folder」を選んでいた場合は、0.2 を初めて起動したときに、その NX のパッドの割り当てと表示の設定（StageFailed、ShowLagTime など）を一度だけ引き継ぎます。0.1 が設定のフォルダの `nx` に写した NX のスキンは、もう使わないので消します。
   - 画面の切り替えは NX v2.0 と同じく、黒い板が回りながら閉じて開くシャッターです（タイトルから先へ、設定の出入り、読み込みや演奏をやめたとき、結果から選曲へ）。
   - 設定の画面は 3 列です（左に分類、真ん中に項目、右に説明と見本）。左の列は NX v2.0 と同じく「システム」と「ドラム」の 2 段で、よく使う、システム（画面・音・ゲームプレイ・曲・全般）、ドラム（譜面・自動・叩き分け・タイミング・入力）、練習 の 11 の分類です。↑↓ で選び、←→ で値をその場で変え、Enter で決め（ON / OFF は切り替え、選択肢や数は選ぶ窓を開く）、Esc で戻ります。一覧は端で回らず、何番目か（3 / 12 など）を出します。既定から変えた項目には橙の点が付き、右の列に既定の値と見本を出します。電子ドラムでは HT で上、LT で下、SD で左、FT で右、CY か RD で決定、LC で戻ります（画面の下にいつも出します）。4 つのパッドだけでも、決定で開く窓の中の上下で値を変えられます。選曲の画面から F1 でも開けます。
   - 2. Start で選曲の画面になります（NX v2.0 と同じ配置）。↑↓ で曲を選び、Tab で難易度、Enter で始めます。←→ で右上の並べ替え（フォルダのまま、BOX、曲名、アーティスト、難易度、レベル、遊んだ記録、全曲、スキルの高い 50 曲）を変え、R で今いる BOX の中からランダムに選びます。BOX は Enter で入り、Backspace か Esc で出ます（一番上で Esc を押すとタイトルに戻ります。タイトルで Esc か Quit を選ぶと終わります）。マウスのホイールでも動かせ、曲の帯を押すとそこへ動きます（選んでいる曲を押すと始めます。並べ替えのアイコンも押せます）。電子ドラムは HT / LT で選び、SD / FT で並べ替え、HH を 2 回で難易度、CY で決め、LC で戻ります（LC は Esc と同じで、BOX の中なら BOX を出て、一番上ならタイトルに戻ります）。RD（キーボードは F2）で、右に簡易設定が開きます（一番上に「この曲を区間練習」、その下に設定の「よく使う」と同じ項目と「すべての設定へ」。開いたときは「この曲を区間練習」を選んでいるので、ドラムなら RD → CY で練習メニューが開きます。操作は設定の画面と同じで、LC か Esc で閉じます）。足で踏むパッド（BD・LP）は演奏の合間に踏んでしまいやすいので、どの画面でもメニューの操作には使いません。曲の帯の左のランプはクリアした一番上の難易度の色、上の帯は曲別スキルで、右下の難易度のパネルには難易度ごとのランクと達成率を出します。DTXManiaNX で遊んだ譜面の隣に `score.ini` があれば、曲を探し終えたときに一度だけ、ドラムの一番の達成率とスコア（進み具合のバー、判定の数も）を記録に引き継ぎます。ランク・スキル・New Record・前回のベストにそのまま効きます（音符ごとの結果は無いので、苦手の分析には使いません。自動で叩いたレーンがあった記録は入れません）。始めると NX と同じ読み込みの画面が「Now loading」の音が鳴り終わるまで出て、演奏の画面になります（読み込みの画面で Esc を押すと選曲に戻ります）。
3. 電子ドラムは、つないでおけば起動したときに見つけます。無ければキーボードで叩けます（A S Z D G F H J K L、Q で HH オープン）。
4. 演奏の画面は NX と同じ配置です（スコア、判定の数と達成率・曲別スキル、ゲージ、コンボ、判定の文字とずれ、進み具合のバー、ジャケット）。遊んでいる間は - / = で入力の補正、[ / ] で表示の補正、↑↓ で速さ、F2 で叩いた音（OFF のときは演奏の始めに知らせます）、R でやり直し、← → で巻き戻し・早送りします（幅は設定の「早送り・巻き戻しの幅」、既定 5 秒。NX と同じく、飛んだプレイは記録に残さず STAGE FAILED にもしません）。Esc・Space・Pause で一時停止し、右に一時停止のメニューが開きます（上から「演奏に戻る」「はじめからやり直す」「演奏をやめる」が並び、その下に曲の位置、譜面の速さ・入力の補正（全体）・この曲の補正・補正のおすすめ・表示の補正・叩いた音・全体の音量・ずれの表示・ずれのバー。「演奏をやめる」は結果の画面を出さずに選曲に戻り、ここまでの演奏は記録に残ります。電子ドラムでも設定の画面と同じパッドで操作でき、LC か Esc で演奏に戻ります）。I で設定と入力の情報（音の出力、MIDI の入力、最後に叩いたパッドとハイハットの開き具合）を出します。ゲージが尽きると、NX と同じく STAGE FAILED で選曲に戻ります（設定の「ゲージ切れで中断」を OFF にすると終わらなくなります。練習では終わりません）。判定の下のずれの数字は設定の「ずれの表示」と「ずれの色」に従います。
5. 最後まで叩くと、NX と同じ結果の画面になります（ランク、Excellent・フルコンボ・ステージクリア、判定の数と割合、スコア、達成率と曲別スキル、今回と自己ベストの進み具合のバー、達成率が自己ベストを超えたら New Record、それぞれの音）。設定の「早い・遅いの数」が ON なら、早かった数と遅かった数も出します。← → で 2 ページ目（このアプリの分析）と切り替え、Enter か Esc で選曲へ、R でもう一度、P で区間を練習します。電子ドラムは SD でもう一度、RD で区間練習、CY か LC で選曲へ、HT か LT でページを切り替えます（画面の下にいつも出します）。

曲の音は WAV・OGG・MP3 のほか、古い曲がドラムの音によく使う XA（BandJAM XA、`.xa`）も鳴らします。

設定（曲のフォルダ・補正値など）は `config.toml` に残ります（Windows は `%APPDATA%\DTXmaniaNXT`）。

アプリのログ（動作の記録）は同じフォルダの `dtxmanianxt.log` に書きます（前回の分は `dtxmanianxt.prev.log`）。Windows ではコンソールの窓を出さないので、うまく動かないときはこのファイルを見てください。起動できなかったときや落ちたときは、その場所をダイアログで知らせます。

遊んだ記録は、音符 1 つごとの判定・ずれ・強さまで同じフォルダの `records.sqlite` に残ります。自己ベスト（達成率、スコア、進み具合のバー）もここから出します（途中でやめたプレイと STAGE FAILED は自己ベストの達成率に入れず、進み具合のバーだけ、最後まで遊んだ記録が無ければ一番先まで進んだものを出します）。結果の画面の 2 ページ目には、直近の記録から出した「苦手な小節」の帯（赤いほど苦手）と、苦手なフレーズの上位 5 つが出ます。小節の番号は DTX の小節番号（`#xxxyy` の `xxx`）です。

## ずれを合わせる

- 補正は 2 つあります。「入力の補正（全体）」はすべての曲の判定をずらします（機材の遅れ向け）。「この曲の補正」は曲ごとの値で、全体に足して使います（難易度はまとめて 1 つ）。判定と譜面の流れを一緒にずらすので、譜面と BGM が合っていない曲にも使えます。選曲の簡易設定（RD か F2）、一時停止のメニュー、選曲から開いた設定の「タイミング」で変えられます。
- 演奏中は左のスコアの下（練習では左下の、成績の下）に「ずれのバー」が出ます。レーンにはかぶせません。真ん中が ±0、左が早い、右が遅いで、叩いた音符ごとに判定の色の線が出て 4 秒で消えます。帯は判定の幅、▼ と数字は直近 20 打の平均です。設定の「ずれのバー」で消せます。
- 結果の画面の 1 ページ目の「ずれ」に、今回のずれの散らばりと、この曲とすべての曲のずれ、補正のおすすめが出ます。おすすめは記録のずれに、そのときの補正を足し戻して出します。全体は直近 15 曲（曲ごとに直近 5 回の平均）の中央値、この曲はこの曲のずれと全体の差です。叩けた音符が 50 に満たない曲は使わず、3 ms より小さい変化はすすめません。等速未満の練習の周、自動演奏だけのプレイ、早送り・巻き戻ししたプレイは使いません。FT（キーボードは O）を叩くとおすすめの値になり、もう一度叩くと元に戻ります。設定の行の「おすすめにする」でも同じ値にできます。

## 区間を練習する

選曲の画面か結果の画面で P を押す（結果の画面では苦手フレーズを押しても）と、練習メニューが開きます。ドラムでは、選曲は RD → CY（簡易設定の一番上）、結果の画面は RD です。

練習メニューの左には、遊んだ記録から出した「苦手な所」が苦手な順に並びます。札ごとに区間の小さな譜面の絵が付き、右にはカーソルの所の大きな譜面の絵が出ます。絵は行がパッド（上からシンバル、ハイハット、タム、スネア、バスドラ）、横が時間で、よくミスする音には輪が付きます（1 回は黄、2 回からは赤で「×2」）。小節の番号だけでなく、どのフレーズのことかが見て分かります。選んでいる所の音（BGM と叩く音）もくり返し流れ、白い線が今鳴っている所を指します（曲の音を読み終えるまでは絵だけです）。練習と同じく、区間の 1 小節前から 4 拍のカウント付きで流れ、白い線は区間に入ってから出ます。

操作は設定の画面と同じです。↑↓（HT / LT）で選び、Enter（CY / RD）で決め、Esc（LC）で選曲に戻ります。パッドの役目は画面の下に出します。開いたときは一番苦手な所を選んでいるので、そのまま決めればすぐ始まります。

練習を終えると（クリアしても、途中でやめても）、結果の画面から練習メニューに戻ります。苦手な所の並びは変わらず、クリアした所には「✓ 100%」の印が付き、カーソルは次のまだクリアしていない所に移ります。次を始めるかどうかは自分で決めます（勝手には始まりません）。一時停止のメニューの「練習メニューへ」でも戻れます。

1. 苦手な所の下の「自分で選ぶ」で、←→（SD / FT）で区間を 1 小節ずつずらし、「長さ」で長さを変えます。マウスなら小節の帯をドラッグしても選べます（クリックで 1 小節）。
2. 「速度・くり返し方」を開くと、右に次の行が出ます。周のくり返し方を選びます。「切れ目なく」は区間の終わりから切れ目なく頭へ戻り、「毎回区切る」は次の小節の頭の 1 打（着地）まで叩いて、区間の 1 小節前からやり直します。
3. 速度の決め方を選びます。
   - 段階アップ（既定）: 始めの速度（既定 70%）から目標の速度（100%、105%、110% から選ぶ）まで、10% ずつの段をのぼります。目標の段を越えたらクリアです。メニューに「70 → 80 → 90 → 100%（4 段）」と段の数が出ます。
   - 固定: 25〜150% の決めた速度の 1 段だけです。越えたらクリア。
   - 遅くするときの音は「保つ」（音程を保つ）か「一緒に下げる」（テープと同じ）から選べます。
   - メトロノーム（既定はオン）: 区間のあいだ拍ごとに小さくクリックを鳴らします（小節の頭は強く）。
4. 「練習を始める」で始めると、区間の 1 小節前から BGM が流れ、クリックで 4 拍数えてから区間を繰り返します。判定の幅は遅くしても実際のミリ秒のままなので、遅い周でも判定は甘くなりません。
5. 段の決まり:
   - 1 段は 4 周です。同じ拍で 2 回ミス（POOR か MISS）しなければ、4 周を叩き終えたところで止まらずに次の段へ進みます。違う拍のミスがばらばらに出るのは数えません。空打ちとずれも数えません（結果の画面で知らせます）。
   - 同じ拍で 2 回目のミスが出たら、その周の終わりで段を区切り、同じ速度で「もう一度」です。「もう一度」が 2 回続いたら、自動で 1 段（10%）下げます。始めの速度より下にも下がります。
   - 途中で選ぶものはありません。目標の段を越えたら「クリア！」が出て、3 秒で結果の画面になります。
   - 1 段の周回数（3・4・6・8 周）と、合格の基準（何回のミスで「もう一度」にするか。ゆるい 3 回・ふつう 2 回・きびしい 1 回）は、設定の「練習」で変えられます。
6. 練習中の画面:
   - 左上に、この段の何周目（「2 / 4」）と今の速度。その下に区間の譜面の絵があり、この段でミスした音に輪が付きます（1 回は黄、決まりの回数に届いたら赤）。
   - 右（ジャケットの場所）に、目標と「あと 2 段」、段の絵（越えた段は緑に ✓、今の段は橙に「いまここ」、いちばん上に旗）、この段の 4 周の丸（ノーミスは緑、ミスがあった周は黄、今の周は橙）。
   - 「もう一度」の段では、2 回ミスした拍がレーンの上で赤く光ります。
   - 叩いているあいだは、レーンの真ん中に何も重ねません。段の変わり目は、区間の 1 小節前からの演奏と 4 拍のカウントをはさみ、その間だけ「OK! 次は 90%」「もう一度 80%」「70% に下げます」を出します（判定の音符が落ちてくる前に消えます）。「もう一度」のときは、ミスが重なった小節の譜面の絵も出し、その拍を赤く塗ります。
   - 止めるときは叩くのをやめます。1 周（区間の前の 1 小節を含めて。短い区間でも 4 秒）何も叩かなければ一時停止のメニューが開きます（キーボードなら Esc か Space）。叩かなかった周は成績にも記録にも入れず、「もう一度」にも数えません。「練習に戻る」を選ぶと、残りの周のあとに区間の 1 小節前から始め直し、同じ段を 1 周目から数え直します。
   - 一時停止のメニューの上の方に、練習に戻る・区間のはじめから・練習メニューへ（ここまでの周を記録に残して、練習メニューに戻ります）・練習をやめる（結果へ。練習はスコアと自己ベストには入りません）が並びます。
   - キーボードでは、←→ で区間を 1 小節ずらし、, と . で速度を 1 段（固定なら 5%）変え（次の周から。その段は 1 周目から数え直し）、R で最初から。
7. 結果の画面には、段の絵（段ごとの挑戦を緑の OK と赤の「もう一度」の点で）、練習した時間、叩いた周、ノーミスの周、全部の周でミスした音を印にした譜面の絵（いちばんミスした拍は赤く塗ります）が出ます。→（HT / LT）で周ごとの成績の表です。SD（R）で同じ決めごとでもう一度、CY・RD・LC（Enter）で練習メニューへ戻ります。空打ちが一つのパッドの弱い打に偏っていればパッドの拾いすぎを（設定の「MIDI 機器」で最小ベロシティを上げると減ります）、ずれの平均が 10ms 以上なら入力の補正を知らせます。

速度が変わるのは段の変わり目と、手で変えたときだけです。「切れ目なく」では次の周がもう落ちてきていることがあるので、段が決まったときや手で変えたときは、まだ始まっていない次の周を取り下げ、新しい速度の助走から並べ直します（次の周の音が鳴り始める間際で間に合わないときだけ、次の次の周から変わります）。

最後まで叩いた周は速度と一緒に記録に残ります。苦手な小節の色に使うのは 100% で叩いた周だけです。

BGM は区間の分だけを 1 本にまとめ、速度ごとに別のスレッドで伸ばしておきます。音程を保つ伸ばしには [timestretch](https://github.com/robmorgan/timestretch-rs)（MIT、Rust だけで書かれていて、ビルドに C++ や LLVM が要らない）を使います。叩いた音とクリックは伸ばしません。

## 克服と叩き方のくせ

- 練習で等速以上の速度の段を越えると、その区間は「クリア」として残ります。そのあとの普通のプレイで、区間を全部叩いて苦手でなく（点が 0.25 未満）、区間の苦手度が練習の前より下がっていれば、結果の画面に「克服！」と出ます。クリアした区間と克服したかは、区間を選ぶ画面にも並びます。
- 結果の画面の「叩き方のくせ」は、すべての曲の等速で叩いた直近 200 回の記録から、レーンと拍の中の位置（表拍、8 分裏、16 分裏、3 連符、細かい位置）ごとにずれの平均とばらつきを出したものです。平均が 8ms 以上ずれている組を、ずれの大きい順に 3 つまで文で出し、全部の組は表で見られます（組ごとに 20 打から）。この版より前の記録は拍の中の位置を持たないので入りません。

## 上達の記録

選曲の簡易設定（RD）の「この曲の記録」で開きます。選んでいる譜面のグラフから見られます。

- 上の段は練習した時間です。曲を遊んだ時間を緑、区間練習の時間をオレンジで日ごとに積み上げます。日は朝 4 時で切り替わり、週は月曜から数えます。SD と FT（←→）で直近 4 週・直近 12 週・すべて（週ごと）を切り替えます。
- 「続けて」は 2 日以上続けて遊んだときだけ出し、それより短いときは遊んだ日の数を出します。今日まだ遊んでいなくても、昨日まで続いていれば数は消えません。
- 左下は曲の一覧で、最近遊んだ順に並びます。右の数字はその譜面のベストの達成率と、初回からベストまでの伸びです。伸びはベストを使うので、調子の悪い日があっても減りません。
- 右下は選んでいる譜面の達成率の移り変わり（最後まで遊んだ回、直近 30 回）と、ずれのばらつきです。ばらつきは小さいほど上に描きます。区間練習でクリアした所には、そのあとのプレイとの間にオレンジの印を立てます。
- CY（Enter）でその曲を選曲で選び、LC（Esc）で選曲に戻ります。
- 遊んだ時間は、このバージョンから 1 回ごとに記録します。前のバージョンの記録は、譜面のテンポと遊んだ小節から長さを見積もって数えます。オートだけのプレイと、1 打も叩かなかったプレイは数えません。

## ランキングとリプレイ

選曲の画面の左上に、選んでいる譜面のスコアの高い順に上位 5 件が出ます。普通に遊んだプレイと、NX から引き継いだ記録が並びます。オートで叩くレーンがあったプレイと、区間練習・基礎練習は入りません。

- ▶ が明るい記録はリプレイを見られます。行をクリックするか、キーボードの V でランキングに入って ↑↓ で選び、Enter で再生します。ランキングの上でホイールを回すと 6 位から下も見られます。Esc（または V）でランキングから出ます。ランキングはパッドでは操作しません。
- 引き継いだ記録はスコアしか無いので再生できません（「引き継ぎ」の札）。途中でやめたプレイには「途中まで」、そのあと譜面を書き換えたプレイには「譜面変更」の札が付きます。
- 結果の画面の HH（キーボードは V）からは、今遊んだプレイのリプレイが見られます。
- リプレイは遊んだときの演奏の画面のまま、BGM と叩いた音を叩いた時刻どおりに鳴らします。叩いた所は音符と一緒に流れる白い線で、音符の無い所を叩いたら赤い線です。CY（Space）で止めると、止めた所の 2 小節を横の譜面と 1 打ずつのずれのグラフで見せます。HT・LT（←→）で小節を送り、RD（P）でその 2 小節を区間練習に選び、LC（Esc）で戻ります。

## 開発者メニュー（調べた結果を issue で送る）

電子ドラムをつないだ PC と開発に使う PC が別のときに、ドラム側の PC で調べた結果を GitHub の issue にして渡すための画面です。ふだんは出ません。

- 出し方: 設定 ＞ 全般 の「バージョン」を 3 秒以内の間隔で 7 回続けて決定すると、開発者モードになり、その下に「開発者メニュー」が出ます。隠すときは「開発者モードを OFF にする」。
- 調べられるもの: 環境の情報（バージョン・OS・音の出力・MIDI 機器）、MIDI の記録（10 秒のあいだに届いたものを全部。記録中は叩いても画面は動かないので、早めに終えるなら Enter、キャンセルは Esc）、ログ、前回のログ、テスト用のツール（V51 の測定など）。
- 終わると右に issue の下書きが出ます。ユーザー名の入ったフォルダの場所（`C:\Users\名前` など）、PC の名前、メールアドレスは伏せてあります。公開のリポジトリに載るので、送る前に中身を確かめてください。
- 「ブラウザで issue を作る」で、下書きを入れた GitHub の新しい issue の画面が開きます。そこで送ります。本文が長くて URL に入りきらないときは、ゲームが本文をクリップボードに入れるので、本文の欄に貼り付けます。GitHub のサインインを求められたら、サインインしてからもう一度押してください。
- 下書きはいつも設定のフォルダ（Windows は `%APPDATA%\DTXmaniaNXT\reports`）にも保存します。「ファイルを見る」で開き、issue にドラッグして添えることもできます。
- ゲームに GitHub のトークンは入っていません。送るのはいつもブラウザで、自分のアカウントからです。

試験の道具を足すとき（開発者向け）: `crates/app/src/dev_report.rs` の `TOOLS` に `Tool` を 1 つ足します。`run` は別のスレッドで呼ばれ、`cancel` が立ったら後片付けをして戻り、`Finding { title, body }`（body は Markdown、5 万文字まで）を返します。始める前に確かめることがあれば `confirm` に書きます。ゲームを閉じたときに道具が動いていれば、取りやめを頼んで 10 秒まで待ちます。
